# FuwaTalk VR

[English](README.md) | **日本語**

VRChat用の音声翻訳・アニメ風字幕アプリです。翻訳は自分のPC上で行われます。

- **自分 → 相手:** 話した内容が翻訳され、VRChatのチャットボックスに表示されます。合成音声で読み上げることもできます。
- **相手 → 自分:** 近くの人の話が翻訳され、ヘッドセットや画面に字幕で表示されます。

> **友人限定です。** 個人の非営利プロジェクトです。インストールには、作者から受け取る個人用キーが必要です。

## ダウンロードの前に

- **現在翻訳できる言語:** 英語、スペイン語、フランス語。**日本語の翻訳はまだ使えません。**
- **アプリは英語で開きます。** 左下の選択欄で、画面を日本語またはスペイン語に変えられます。このページでは日本語表示の名前を *(斜体)* で書いています。インストーラーは英語です。
- Windows 10(バージョン2004)以降、64ビット。
- NVIDIAのグラフィックボードを推奨します。AMDとIntelではDirectMLを使いますが、AMDの実機ではまだ試していません。グラフィックボードなしでも動きますが、遅くなります。
- 選んだ翻訳モデルに応じて、約1〜7 GBのAIモデルを最初に一度だけダウンロードします。

## インストール

1. [Releases](../../releases/latest) から `FuwaTalk-X.Y.Z-setup.exe` をダウンロードします。`actualizacion` のファイルはアプリが自動更新に使うものなので、不要です。
2. ファイルを開き、キー(`FUWA-` で始まります)を貼り付けて、質問に答えます。
   - 男性か女性か:合成音声の種類を選びます。
   - 年齢:18歳未満の場合、暴言フィルターがオンになります。いつでも切り替えられます。
   - 母語と、翻訳先の言語。
   - 使う翻訳モデル。PCに合ったものに「Recommended」の印が付きます。
   - VB-Cableを入れるかどうか(合成音声を使う場合だけ必要です)。
3. 初めて開いたときに、選んだものがダウンロードされます。

すでに入っている場合は、インストーラーをもう一度開くと、更新や修復、回答の変更、アンインストールができます。

## VRChatの設定(最初の一度だけ)

1. OSCをオンにします:ラジアルメニュー → *Options* → *OSC* → *Enabled*。
2. 翻訳を相手に聞かせたい場合だけ:*Settings* → *Audio* → *Microphone* → **CABLE Output (VB-Audio Virtual Cable)**。

FuwaTalkを開いている間は、合成音声がオフなら、あなたの本当の声もこのケーブルに送られます。**アプリを閉じたら、VRChatのマイクを普段のものに戻してください。** 戻さないと声が届きません。

## できること

### 自分の声を翻訳
- 普通に話すだけです。文が終わると、翻訳が**チャットボックス**に送られます(入力中の表示も出ます)。
- 長い文はページに分かれます。先頭の記号、1ページの表示時間、通知音、原文を付けるかどうかを設定できます。
- 話す言語と翻訳先を選び、ボタンひとつで入れ替えられます。
- プッシュ・トゥ・トークも使えます。VRChatでミュート中は、翻訳も読み上げもしません。

### 合成音声(TTS)
- **オン:** VRChatでは、翻訳を読み上げる合成音声だけが聞こえます。
- **オフ:** 自分の本当の声が聞こえ、翻訳はチャットボックスに表示されます。
- 英語とスペイン語は女性と男性の声、フランス語は女性の声だけです。
- 言語ごとに声を選んで試聴できます。速さと音量を調整でき、自分で聞くこともできます。
- **事前に確認**:確認するまで読み上げません。

### 相手の話の字幕
- **VR:** SteamVRのオーバーレイ。距離、高さ、幅、頭への追従を調整できます。
- **デスクトップ:** VRChatのウィンドウの上に表示します。初期設定では、VRがないときに自動で表示します。
- **話し相手だけ**:話している相手だけに字幕を付けます。特定の声に固定できます。
- **会話**:複数の声を同時に、それぞれ違う色で表示します。
- **字幕を付ける相手:** 全員から、すぐ隣の人だけまで、スライダーで選べます。
- 長く話す人の字幕は、話している途中から少しずつ表示されます。
- 文字の大きさ、縁取り、透明度、背景の帯、行数、表示時間を調整できます。

VRChatはプレイヤーの位置を共有しないため、距離は音量、方向、声の特徴から*推定*しています。間違うこともあり、2人が完全に同時に話すと混ざることがあります。

### 文字入力モード
- 話す代わりに文字を入力します。翻訳して(または、そのまま)読み上げ、チャットボックスに送ります。
- VRではSteamVRのキーボード、デスクトップではVRChatの上に小さな入力欄が開きます。
- オンの間、本当のマイクをミュートできます。

### 暴言フィルター
- チャットボックスと字幕では `****`、合成音声ではピー音になります。自分で単語を追加できます。
- 自分の本当の声や、ほかの人の声は**隠しません**。

### プライバシー
- 音声認識、翻訳、合成音声はPC上で動きます。音声や文章を翻訳サービスに送ることはありません。
- インターネットは、モデルとVB-Cableのダウンロード、GitHubでの新しいバージョンと無効になったキーの確認に使います。チャットボックスに送った翻訳は、通常どおりVRChatに送られます。
- **履歴**は自分のPCだけに、初期設定では30日間保存されます。検索、書き出し、削除、オフにすることができます。
- **プライベートモード**:相手の話をディスクに保存しません。

### その他
- **用語集:** 翻訳しない単語と、訳の修正を登録できます。
- **ホットキー:** ゲーム中も使え、変更できます。
- **SteamVR:** SteamVRと一緒に開き、そのまま翻訳を始めることができます。
- **一時停止:** グラフィックメモリを解放します。この機能はオフにできます。
- **更新:** 新しいバージョンをお知らせし、確認してからインストールします。ダウンロードが途中で切れても、続きから再開します。

## ホットキー

| キー | 動作 |
|---|---|
| `Ctrl+Alt+T` | 一時停止 / 再開 |
| `Ctrl+Alt+L` | 話し相手の固定 / 解除 |
| `Ctrl+Alt+Enter` | 確認待ちの翻訳を読み上げる(事前に確認モード) |
| `Ctrl+Alt+Space` | プッシュ・トゥ・トーク(オンにした場合) |
| `Ctrl+Alt+K` | 文字を入力する |

## PCに合わせた選択

| アプリでの名前 | グラフィックメモリ(NVIDIA) | モデルのダウンロード | 結果 |
|---|---|---|---|
| *グラボなしのPC* | なし | 約1.3 GB | 動くが遅い |
| *低性能のPC* | 1 GB未満 | 約1.3 GB | とても軽い。逐語的で、間違うこともある |
| *標準のPC* | 約3 GB | 約5.3 GB | 自然な翻訳 |
| *高性能のPC* | 約4.5 GB | 約7 GB | 最も良い。冗談や言い回しをよりよく理解する |

ゲームがカクつく場合は、*設定*で下のものを選んでください。

## 困ったとき

| 問題 | 対処 |
|---|---|
| チャットボックスに何も出ない | VRChatでOSCをオンにし、*チャットボックス* のページからテストメッセージを送る |
| 合成音声が相手に聞こえない | VRChatのマイクを `CABLE Output` にし、*合成音声(TTS)* をオンにする |
| 自分の声が相手に聞こえない | FuwaTalkを開いたままにするか、普段のマイクに戻す |
| VRで字幕が出ない | SteamVRを開き、*字幕 → ヘッドセット(SteamVR)* を確認する |
| デスクトップで字幕が出ない | *字幕 → 画面* を *常に表示* にし、ゲームをウィンドウまたはボーダーレスにする |
| 雑音や遠い声まで翻訳する | 字幕のスライダーを右に動かす |
| 文が途中で切れる | *設定 → 文の終わりとみなす無音の長さ* の値を上げる |

自動翻訳には間違いがあります。大切なことには頼らないでください。

## クレジット

Whisper(faster-whisper)、NLLB-200、Gemma、Kokoro、eSpeak NG、llama.cpp、PySide6(Qt)、VB-CABLEを使用しています。それぞれ作者のもので、独自のライセンスがあります。

FuwaTalkは非公式のプロジェクトです。VRChat、Valve、VB-Audio、および上記のプロジェクトとは提携しておらず、承認も受けていません。
